## Overview

Berean Bible Bots combines biblical research, morphology, and language-learning resources in one study environment. Its materials are intended for work with the original languages of Scripture and related traditions, including Hebrew, Greek, Aramaic, the Septuagint, the Peshitta, and the Targums.

The project supports both independent investigation and structured instruction. Study groups, teachers, and individual learners can use its lessons, notebooks, reference content, and search tools to examine corpora, compare linguistic forms, and move between guided exercises and research-oriented exploration through a static documentation site.

## Using the Toolkit

The primary workflow involves selecting study material, exploring lessons, analyzing language data, and searching the research library.

A common sequence is:

1. Launch the documentation site or notebook index.
2. Select a corpus or lesson path.
3. Apply morphological or statistical analysis to the chosen text collection.
4. Use semantic search to find relevant terms and passages.
5. Review the results with flashcards or Anki decks when those resources are available.

For MCP-based use, configure a compatible client with the project endpoint and access the study and analysis capabilities provided through the server.

## Configuration

Configuration is generally located alongside the site, notebooks, or other project files that control the study workflow. When running the project locally, inspect the repository root and the documentation or notebook directories for the applicable settings.

A representative configuration structure is:

```yaml
corpora:
  - hebrew
  - greek
  - septuagint
  - peshitta
  - targum
study_mode: lessons
search_mode: semantic
```

Modify corpus selections, lesson locations, and search behavior according to the type of study you want to perform and the details of your local installation.
